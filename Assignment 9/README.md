
# Assignment 9 - Campus Collective

## Project Overview
Campus Collective is a fully responsive student
community landing page built using HTML5 and CSS3.

The website helps students learn, collaborate,
share ideas and participate in campus activities.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts

## Layout Implementation

### Flexbox
- Navigation bar
- Hero buttons
- Feature card content
- Footer links

### CSS Grid
- About section
- Statistics section
- Feature cards
- Gallery section
- Contact section

## Responsive Design
- Desktop: 1200px
- Tablet: 768px
- Mobile: 375px

## Main Features
1. Responsive navigation bar
2. Hero section
3. About section
4. Six feature cards
5. Community gallery
6. Call-to-action section
7. Contact form
8. Responsive footer

## Design Choices
Dark green represents stability and growth.
Light green gives a fresh and peaceful appearance.
Teal highlights buttons and important elements.
Golden accents add visual contrast.

Poppins is used throughout the website
for a clean and modern appearance.
